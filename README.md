# AI Drone 실습 코드 모음

숭신여자고등학교 학생 대상 AI 드론 교육에 활용한 Python 실습 코드 모음.

## 1. 프로젝트 개요

- **목적**: AI 기반 얼굴 및 손 인식 기술과 드론 제어 기능을 연계하는 실습 자료 제공
- **활용 분야**: 컴퓨터 비전 기초, 얼굴 인식, 손동작 인식, 드론 제어 실습
- **개발 환경**: Python
- **주요 라이브러리**: OpenCV, MediaPipe
- **드론 제어**: CodingRider SDK 기반

## 2. 파일 구성

| 파일명 | 주요 기능 |
|---|---|
| `1_face_detection.py` | OpenCV 기반 얼굴 검출 |
| `2_face_drone1(coordinate).py` | MediaPipe 기반 얼굴 검출 및 좌표 확인 |
| `3_face_drone(steering).py` | 얼굴 좌표 기반 드론 제어 |
| `4_face_drone(improve).py` | 얼굴 추적 및 드론 제어 개선 |
| `4_face_drone(improve)` | 확장자 없는 파일. 별도 확인 필요 |
| `5_hand_drone.py` | 손가락 좌표 기반 드론 제어 |
| `exam.py` | Python 및 주요 라이브러리 설치 환경 점검 |
| `haarcascade_frontalface_default.xml` | OpenCV 얼굴 검출용 Haar Cascade 모델 파일 |

## 3. 실습 내용

### 3.1. 얼굴 검출

OpenCV의 Haar Cascade를 활용하여 카메라 영상에서 얼굴을 검출하고, 검출된 영역을 사각형으로 표시하는 실습.

### 3.2. 얼굴 좌표 인식

MediaPipe Face Detection을 활용하여 얼굴과 주요 기준점의 좌표를 확인하고, 영상 내 얼굴 위치를 분석하는 실습.

### 3.3. 얼굴 위치 기반 드론 제어

얼굴의 기준점 좌표를 이용하여 드론의 이동 방향을 제어하는 실습. 기본 제어 기능을 구현한 후 얼굴 검출 및 추적 로직을 개선하는 방식으로 구성.

### 3.4. 손동작 기반 드론 제어

MediaPipe Hands를 활용하여 손의 랜드마크 좌표를 검출하고, 검지 끝 좌표를 기준으로 드론의 이동 방향을 제어하는 실습.

### 3.5. 개발 환경 점검

Python 실행 환경과 주요 라이브러리의 설치 여부 및 GPU 관련 환경 정보를 확인하는 진단 코드.

## 4. 실행 환경 및 유의 사항

- Python 및 OpenCV, MediaPipe 등 필요한 라이브러리 설치 필요.
- 드론 제어 실습은 CodingRider SDK 및 해당 드론 연결 환경 구성 필요.
- 코드에 지정된 시리얼 포트(`COM3`, `COM4`)는 실제 연결 환경에 맞게 수정 필요.
- 카메라 연결 상태 및 운영체제별 장치 접근 권한 확인 필요.
- 드론 구동 전 비행 공간과 주변 안전 상태 확인 필요.

## 5. 조작 방법

드론 제어 코드에 구현된 기본 키 입력은 다음과 같음.

| 입력 키 | 기능 |
|---|---|
| `Enter` | 이륙 |
| `Space` | 착륙 |
| `Q` | 프로그램 종료 처리 |
| `ESC` | 일부 코드에서 영상 창 종료 |

세부 동작은 파일별 구현에 따라 차이가 있을 수 있으므로 실행 전 코드 확인 필요.
